# 圖片檔命名與引用規範（瑞典地理課本）

## 建議命名
- 章節圖：`ch01-fig01-sweden-europe-nordic.png`
- 章節地圖：`ch01-map01-location-europe-nordic.png`
- 章節照片：`ch01-photo01-stockholm-archipelago.jpg`

## 建議格式
- 地圖／示意圖：`png`（線條與文字較清晰）
- 照片：`jpg`（檔案較小）
- 若需透明背景：`png`

## 圖題與來源（務必保留）
每張圖請至少保留以下資訊（可寫在章檔圖題下方，或寫在圖片旁的註記區）：
- 圖題（含圖號）
- 圖說（1–2 句，告訴讀者「這張圖要看什麼」）
- 來源（作者/機構/網址/取用日期）或「自製」（並註明底圖/資料來源）
